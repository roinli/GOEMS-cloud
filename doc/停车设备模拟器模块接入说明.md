# 停车设备模拟器模块接入说明

## 1. 模块说明

`witos-parking-simulator` 是独立微服务，负责模拟停车场道闸设备通过 HTTP 与 `witos-parking` 交互。

已实现能力：

1. 从数据库读取全部停车设备并展示模拟状态
2. 启动/停止模拟器
3. 上线/下线模拟设备
4. 定时自动发送心跳
5. 手动发送心跳
6. 手动模拟入场
7. 手动模拟出场
8. 出场允许开闸时自动回调开闸结果

## 2. 需要执行的 SQL

先执行：

1. [`parking_simulator_v1.sql`](/F:/jianzhi/parking/witos-platform/sql/parking_simulator_v1.sql)

## 3. Nacos 配置

新增一个配置项：

- Data ID: `witos-parking-simulator-dev.yml`
- Group: `DEFAULT_GROUP`

内容可直接参考：

- [`witos-parking-simulator-dev.yml`](/F:/jianzhi/parking/witos-platform/doc/witos-parking-simulator-dev.yml)

同时你现有 `application-dev.yml` 里的多租户忽略表要补一项：

```yml
witos:
  tenant:
    ignore-tables:
      - parking_simulator_device
```

## 4. 网关修改点

网关 Nacos 配置 `witos-gateway-dev.yml` 里确认停车模块路由存在。如果之前没有加过，先补：

```yml
- id: witos-parking
  uri: lb://witos-parking
  predicates:
    - Path=/parking/**
  filters:
    - StripPrefix=1
```

再新增模拟器模块路由：

```yml
- id: witos-parking-simulator
  uri: lb://witos-parking-simulator
  predicates:
    - Path=/parking-simulator/**
  filters:
    - StripPrefix=1
```

停车模块开放给设备的接口需要放到白名单，因为模拟器和真实设备一样，不带后台用户登录态：

```yml
security:
  ignore:
    whites:
      - /parking/open/device/**
```

说明：

1. 模拟器后台接口需要登录，不需要加入白名单
2. Swagger 已有 `/*/v2/api-docs` 白名单，无需额外处理

## 5. 菜单与权限

本次新增权限：

1. `parking:simulator:list`
2. `parking:simulator:query`
3. `parking:simulator:edit`
4. `parking:simulator:operate`

菜单组件路径预留为：

```text
parking/simulator/index
```

如果你当前阶段不做前端，这条菜单可以先保留，后续页面补上后直接可用。

## 6. 本地联调地址

建议本地联调走网关：

1. 网关：`http://127.0.0.1:48080`
2. 停车模块开放接口根路径：`http://127.0.0.1:48080/parking`
3. 模拟器模块后台接口根路径：`http://127.0.0.1:48080/parking-simulator`

## 7. 交互说明

模拟器模块不会直接写停车业务表，而是通过 HTTP 调用停车模块开放接口：

1. 心跳：`POST /parking/open/device/event/heartbeat`
2. 入场：`POST /parking/open/device/event/entry`
3. 出场：`POST /parking/open/device/event/exit`
4. 开闸回调：`POST /parking/open/device/command/callback`

这样后续替换成真实硬件时，平台侧接口可以继续复用。
